# Wenzgram

Форк [Telegram Desktop](https://github.com/telegramdesktop/tdesktop) с защитой локальной сессии от кражи.

## Защита сессии

Исходники клиента находятся в каталоге [`telegram-desktop/`](telegram-desktop/).

Реализована **привязка сессии к устройству и установке клиента**:

1. **Отпечаток устройства** — уникальный ID машины (machine-id, hostname, boot-id).
2. **ID установки** — случайный секрет, создаётся при первом запуске и хранится в `tdata/install_id`.
3. **Шифрование tdata** — ключи шифрования локальных данных (`CreateLocalKey` / `CreateLegacyLocalKey`) выводятся с учётом отпечатка устройства и ID установки.
4. **Проверка при запуске** — в файле ключа сохраняется хэш привязки; при несовпадении клиент отказывается открывать сессию.

### Что это даёт

- Если кто-то скопирует папку `tdata` на **другой компьютер** — войти не получится.
- Если скопируют `tdata` в **другую папку/установку** на том же ПК — тоже не получится (другой `install_id`).
- При попытке открыть чужую сессию показывается сообщение об ошибке, данные **не удаляются**.

### Ограничения

- Защита действует для **этого клиента (Wenzgram)**. Если злоумышленник извлечёт `auth_key` из памяти процесса, он теоретически может использовать его в стороннем MTProto-клиенте (Telethon и т.п.) — для этого нужен отдельный серверный контроль, которого у публичных серверов Telegram нет.
- Сессии из **оригинального Telegram Desktop** несовместимы — потребуется войти заново.
- Рекомендуется также включить **локальный пароль** в настройках для дополнительной защиты.

## Изменённые файлы

| Файл | Назначение |
|------|------------|
| `storage/session_device_binding.*` | Генерация отпечатка устройства и материала для KDF |
| `storage/details/storage_file_utilities.*` | Привязка KDF к устройству |
| `storage/storage_domain.*` | Сохранение/проверка хэша привязки в key-файле |
| `core/application.cpp` | UI при несовпадении устройства |
| `window/window_lock_widgets.cpp` | Сообщение при вводе пароля на чужом устройстве |
| `wenzgram/wenzgram_settings.*` | Настройки мода Wenzgram |
| `wenzgram/wenzgram_local_wallpapers.*` | Локальные обои для чатов (только на этом устройстве) |
| `settings/sections/settings_wenzgram.*` | Раздел «Wenzgram» в настройках |
| `wenzgram/wenzgram_deleted_messages.*` | Отображение удалённых сообщений локально |

## Настройки Wenzgram

В **Настройки → Wenzgram** доступны опции мода:

- **Локальные обои для чатов** — фон чата только у вас, без синхронизации с Telegram
- **Показывать удалённые сообщения** — удалённые сообщения остаются в чате с меткой «УДАЛЕНО»
- Внешний вид: брендинг, компактный список чатов, крупные эмодзи и др.
- Поведение: подтверждение отправки, копирование @username и др.
- Информация о защите сессии

### Локальные обои

1. Включите опцию в **Настройки → Wenzgram**
2. Откройте чат → меню **⋮** → **Локальные обои**
3. Выберите изображение и нажмите **Применить локально**

Обои сохраняются в `tdata/user_*/wenzgram/wallpapers/` и не отправляются на сервер.

### Удалённые сообщения

При включённой опции удалённые сообщения **не исчезают** из чата — остаются с красной меткой **«УДАЛЕНО»**. Работает для сообщений, удалённых пока клиент запущен (включая «удалить для всех»).
